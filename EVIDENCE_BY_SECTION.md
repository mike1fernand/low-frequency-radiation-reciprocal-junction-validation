# Where to reproduce the paper

Use the included 13 November scientific snapshot in [the editable manuscript and supplement](manuscript/source/). Later editorial builds can differ in wording; the source-bound tests here target this snapshot. The table follows the paper’s model, stationary response and direct dynamics. Each linked module identifies the inputs and software it needs. Some runs generate large files. Start with [the basic check and platform instructions](RUNNING_VALIDATIONS.md), then use a fresh external output directory as described in the module instructions. [The README index](README_INDEX.md) distinguishes current entry points from retained historical guides.

[Manuscript artwork](validation/artwork/README.md) gives the figure checks. The artwork command regenerates seven of the eight original external assets, including the normalized low-frequency panel, and compares their bytes with the manuscript. All 196 plotted samples in the supplied frequency-partition PDF were checked against its four numerical curves. The original plotting script for that PDF was not located. This edition displays Figure 4 and its SM4 companion as single-panel derivatives of the retained, reproducible two-panel asset.

## Provenance and interpretation

[Historical coverage](history/HISTORICAL_COVERAGE.md) compares the earlier repositories with the first November 11 GitHub package. It lists original archive paths. The table above points to the corresponding locations in this public release. [Public-edition provenance](PUBLIC_SOURCE_PROVENANCE.json) identifies the edits to the two November modules. Each restored validation directory also lists its source files.

The recorded SM1 maximum scaled force-gradient error is `4.204130575684652e-14`, below `4.21e-14`.

The historical generalized-Bloch comparison can be rerun from the saved matrices. Its original generator and regulator convention remain unidentified. A separate, reproducible calculation specifies its regulator and corroborates the approximate reference-taper value. The ramp proof uses a different route. Replaying all saved contour jobs does not freshly integrate their 449,698 leaves.
