The controlling R3 result leaves one substantive optional scientific gate:
tight complete-domain enclosures of the actual selected g and Q matrices.
The proposed R4 work should implement that campaign with the validated
preconditioner, not repeat the previous local pilots. The existing narrower
paper result remains valid on its stated premises and is not made conditional
on this optional strengthening.

## Required campaign and correction gates

1. Bind the exact R3 producer and selected-matrix identities before running.
   Keep new producers and checkpoints separate from sealed R3 evidence.
2. Before first physical run, prove and test compact checkpoint arithmetic:
   complete accepted-plus-pending cover for every required contour leg,
   exact rational addition of outward accepted endpoints, no discarded
   pending boxes, and explicit source/settings/runtime binding. Reject a

   altered source, or corrupted aggregate.

   the matrix row occurrences. The settings control the Cauchy truncation
   allowance, but final acceptance must use complete serialized enclosures,
   including quadrature arithmetic radii and selected-cache displacement.
   Both real and imaginary components enter the complex g modulus.
4. After the first complete physical regions, inspect measured radius/cost
   and only change settings for a concrete bottleneck. Preserve finished
   regions, and compare changed methods on the same region. Timing is
   empirical; no finite easy pilot guarantees a global runtime.
5. After each stage, persist progress and validate the exact cover. The
   physical y/z symmetry permits chart1/chart2 reuse and chart0 transposition
   only with explicit disjoint domain accounting. No permutation involving
   the physical source x-axis is authorized.
6. At final aggregation, check all three unit angular squares, the three qT
   contour legs or four Green legs including exterior, and exact mapping of
   all 17 moments into all 144 matrix entries. Use the actual cached dyadic
   targets rather than a symmetry-cleaned representative.
7. Accept an exact-lattice floor only after both scaled operator budgets
   (.020 for g, .005 for Q) pass, the lower-pair spectral definition still
   supplies exact Q positivity including ties, and the conditional bridge
   is replayed. A failed sufficient bound does not disprove the physical
   result or establish the true approximation error.
8. Conduct one load-bearing pass and one open skeptical-referee pass on the
   new result. Report completed calculation, unresolved cells/widths and
   unperformed verification distinctly. Keep computation-development detail
   in validation material unless a stronger result justifies paper length.

## Scope and checks not needed by default

Do not repeat the unchanged N160 production campaign or donor-paper
calculations. No exact finite-window identity or whole-frequency-band theorem
is needed for the current reference-frequency result. An exact deterministic
certificate is not a calibrated 95-percent probability. The user’s certainty
criterion calls for claim-specific verification, not a numerical confidence
label on algebraic checks.

matrix accounting documentation, complete fallback proof, preconditioner
proof and implementation. It is not a replay of the new R4 code, which had
not yet been written when this note was started.

## Export review issue

The first export auditor required exact `sys.version` equality, including
compiler/build text, to inspect saved dyadic evidence. This is unnecessarily
restrictive for a public read-only proof audit: a compatible Python build can
verify the same fixed endpoint sums and mathematical identities. It is not a
defect in the generated integral values. The minimum recommended correction
is to keep checkpoint resumption strict, retain producer provenance, and let
the saved-evidence auditor use its own separately recorded runtime while
requiring the reviewed mathematical source and python-flint version and
recomputing every canonical check. This does not authorize rewriting saved
identities or claiming a second-platform replication that did not happen.
